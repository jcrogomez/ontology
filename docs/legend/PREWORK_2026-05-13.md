## Why this exists

`SELF_INGEST_HYPOTHESIS_2026-05-13.md` §2 says the Ollama pilot must
validate six checkpoints: perimeter count, proposal schema health, edge
inference, **report shape**, **matrix aggregation**, and **frontier
tagging**. The last three cannot run today because:

- `AggregateReport.byVerdict` (`src/runtime/legend/verify-homeomorphism.ts:239`)
  collapses to a **single 5-label axis**; the hypothesis matrix requires
  **six orthogonal axes**.
- **Zero code references** the 16-attribute frontier vocabulary in
  `POSITIONING.md` §4 / hypothesis §6.
- Required intersection aggregates (`io-bound ∧ structural-drift`, etc.)
  have no computer.

Without this prework, the pilot only re-confirms γ-7-shaped output. With
it, the pilot produces the first artifact evaluable against hypothesis
§7 success criteria.

## A. Multi-positional ingest

**Current** (`src/commands/ingest/index.ts`): `onto ingest <path>` accepts
exactly one positional path.

**Target:** `onto ingest <path> [<path>…]` — N positional paths, union the
file lists, dedup by absolute path, single proposal stream.

**Why not a shell wrapper:** the perimeter shape belongs in the CLI
surface, not in shell history. The hypothesis perimeter is `runtime +
core + commands + schemas`; that fact should be queryable from the tool,
not reconstructed from `bash_history`.

**Acceptance:**

- `onto ingest src/runtime src/core src/commands src/schemas --include ts --cost-estimate --provider ollama`
  prints a single total file count and a per-directory breakdown.
- Existing single-path tests still pass unchanged.
- New test: two directories that share a transitively-walked file
  dedupe (one proposal, not two).

**Estimate:** ~30 min.

## B. Frontier tagger

**New module:** `src/runtime/legend/frontier-tagger.ts`.

**Input:** absolute file path (and optionally its byte contents).
**Output:** `FrontierAttribute[]` where `FrontierAttribute` is the
16-tag union from POSITIONING §4. Empty array is invalid: every file in
the perimeter must receive at least one attribute.

**Path-based rules** (deterministic, no LLM, no file read required):

| Glob | Attributes |
|---|---|
| `src/**/integrity/**` | `pure-transform` |
| `src/schemas/**` | `schema-driven` |
| `src/runtime/effects/**`, `src/runtime/topos/**` | `algebraic-lawful`, `pure-transform` |
| `src/runtime/context/intent-validator.ts`, `src/runtime/topos/rule-compiler.ts` | `declarative-validator`, `schema-driven` |
| `src/commands/**/index.ts` | `cli-parsing`, `operational-glue` |
| `src/core/fs/**`, `src/core/state/**`, `src/runtime/compile/artifact-writer.ts` | `io-bound`, `operational-glue` |
| `src/runtime/llm/**/adapter.ts` | `adapter-boundary`, `io-bound`, `operational-glue` |
| `src/core/fs/lock.ts` | `operational-glue`, `io-bound` |
| `src/walker/**` | `tui-rendering`, `operational-glue` (out of perimeter, useful for later sweeps) |

**Content-based extensions** (optional, still $0):

- File body contains `node.literal === true` or `literal: true` next to
  a prompt template → `literal-required`.
- File body contains `// @human-authored` marker → `human-authored`.
- File body matches `prompt:\s*[\`'"]` block over N chars → `prompt-sensitive`.

**Out of scope for the tagger:** `contract-missing`, `structural-drift`,
`behavior-drift`, `not-reviewed`. Those are verdict-derived and assigned
by the matrix aggregator (C) after verification runs.

**Acceptance:**

- Snapshot test: tag the 117 perimeter files. No file has zero
  attributes.
- Unit tests: one representative path per rule pins its expected
  attribute set.
- The fixture plan from hypothesis §8 — when it exists — would tag
  every fixture file into its predicted bucket without manual edits.

**Estimate:** ~2–4 h.

## C. Matrix aggregator

**Target:** extend `AggregateReport` with a six-axis matrix per node.

```ts
export interface MatrixCell {
  contract: 'pass' | 'fail' | 'unknown' | 'not-measured';
  structural: 'pass' | 'fail' | 'partial' | 'not-measured';
  behavior: 'pass' | 'fail' | 'untested' | 'not-applicable';
  intent: 'accepted' | 'rejected' | 'needs-human' | 'not-reviewed';
  literalRequired: 'true' | 'false' | 'candidate' | 'unknown';
  cost: {
    provider: string;
    model: string;
    task: string;
    inputTokens: number;
    outputTokens: number;
    usd: number;
    wallClockMs: number;
  };
}

export interface PerNodeMatrix {
  nodeId: string;
  sourceFile: string;
  frontier: FrontierAttribute[]; // from B
  cell: MatrixCell;
}
```

**Pilot-time mapping** from existing `HomeomorphismVerdict` →
`MatrixCell.structural`:

| HomeomorphismVerdict | structural | other axes |
|---|---|---|
| `epsilon_equivalent` | `pass` | contract `not-measured`, behavior `untested`, intent `not-reviewed`, literal from `node.literal` |
| `divergent_structural` | `fail` | same |
| `divergent_loc` | `partial` | same |
| `divergent_both` | `fail` | same |
| `unrecoverable` | `not-measured` | intent flips to `needs-human` |

`AggregateReport` extends with:

```ts
matrix: PerNodeMatrix[];
byAxis: {
  contract: Record<MatrixCell['contract'], number>;
  structural: Record<MatrixCell['structural'], number>;
  behavior: Record<MatrixCell['behavior'], number>;
  intent: Record<MatrixCell['intent'], number>;
  literalRequired: Record<MatrixCell['literalRequired'], number>;
};
```

**Acceptance:**

- Existing `verify-homeomorphism --report` emits `byVerdict` unchanged.
- New `--matrix` flag adds `matrix` + `byAxis` to the JSON.
- Unit test pins the verdict→axis mapping for every verdict.
- Pilot output validates against a Zod schema (also new, lives next to
  the types).

**Estimate:** ~2–3 h.

## D. Intersection aggregator

**Target:** `byIntersection: Record<string, number>` on `AggregateReport`.

**Required intersections** (from hypothesis §6 — every report carries
all seven, with explicit zeros when applicable):

- `io-bound ∧ structural-drift`
- `io-bound ∧ behavior-drift`
- `literal-required ∧ prompt-sensitive`
- `cli-parsing ∧ behavior-drift`
- `schema-driven ∧ contract-equivalent`
- `pure-transform ∧ behavior-equivalent`
- `contract-missing ∧ not-reviewed`

**Algorithm:** for each node, compute its full tag set as
`frontier ∪ verdict-derived` (e.g., a node with `structural: 'fail'`
gets `structural-drift` added). Count required-intersection pairs that
match the tag set. Emit the seven counts even when zero.

**Acceptance:**

- All seven intersections present in every report.
- Unit test: synthetic 6-file fixture with hand-set tag sets produces
  pinned counts.
- Additional intersections discovered during the run may be appended;
  required ones must not be removed.

**Estimate:** ~1–2 h.

## Out of scope for this prework

- **Automated `contract-equivalent` checker.** Comparing declared
  `requires` / `provides` / `forbids` between original and regenerated
  nodes is a real piece of code; pilot reports `not-measured` for now.
- **Fixture runner for `behavior-equivalent`.** Wiring `vitest` or
  targeted fixtures against regenerated artifacts is its own stream;
  pilot reports `untested` or `not-applicable`.
- **LLM-aided frontier tagging.** Pilot uses path + content heuristics
  only. An LLM-assisted second pass can lift attribute coverage in a
  later sweep, but it is not $0 and is not pre-pilot.
- **`examples/legend-fixture/`** (hypothesis step 8). Optional companion
  to validate the pipeline deterministically; not required to run the
  Ollama pilot, and may be more useful written *after* the pilot exposes
  which buckets need the strongest sanity checks.
- **`onto verify-homeomorphism` provider routing changes.** Existing
  routing (`f80163d`) is sufficient; cost telemetry already lands in
  `VerificationUsage`.
